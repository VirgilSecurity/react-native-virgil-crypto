# Sample server for File Encryption Example
React Native project is available [here](../FileEncryptionExample).

## Install
```sh
npm install
```

## Usage
- Start the server (runs the TypeScript source directly via `tsx`):
  ```sh
  npm start
  ```
- Or with auto-reload while editing:
  ```sh
  npm run dev
  ```
